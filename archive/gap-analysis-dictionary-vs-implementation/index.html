    PRIORITY GAPS (Recommended Next Steps)¶

    High Priority (Core Functionality)¶

    1. FIXTURE Dictionary - TOILET, SINK, SHOWER placement
    2. Opening offset/sill - Precise door/window positioning
    3. ZONE geometry - OPEN_PLAN zone boundaries
    4. HabitabilityValidator - Natural light, min area checks
    5. BOM Export - Quantities for ERP integration

    Medium Priority (Enhanced Features)¶

    1. LOD Validation - Content completeness per LOD level
    2. Protocol Validation - Full required_spaces/relationships
    3. SpaceType Specialization - Type hierarchy with inheritance
    4. MEP Electrical - Outlets, switches, lighting circuits
    5. Profile Inheritance - Extending profiles

    Lower Priority (Advanced Features)¶

    1. GUTTER modeling - Envelope drainage chain
    2. Furniture Hints - BED, SOFA placement for LOD 400
    3. AS_BUILT LOD 500 - Survey deviation tracking
    4. Full Terminal Protocol - Airport-specific validation
