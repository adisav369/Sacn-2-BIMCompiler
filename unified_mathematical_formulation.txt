## 2. Decomposition: The 5-Stage Pipeline

The compiler `C` decomposes into 5 sequential transformations:

```
C = W ∘ V ∘ R ∘ P ∘ E
```

### Stage E: Element Extraction (IFC → Intent)

```
E: IFC → (Ω₀, Ψ₀, Φ₀)
```

Extracts from source IFC:
- `Ω₀`: OrderLines from element types (wall, door, pipe, etc.)
- `Ψ₀`: Parent-child relationships (room contains walls, wall contains door)
- `Φ₀`: Attributes (width, depth, height, material)

### Stage P: Placement (Intent → Absolute Positions)

```
P: (Ω, Ψ, Φ, Λ, J) → T
```

Where `T` is the set of absolute tacks (x, y, z) for every element.

**The placement equation:**

For an element `e` with parent `p(e)`:

```
T(e) = T(p(e)) + R(θ(e)) · Δ(e)
```

Where:
- `T(p(e))` = absolute tack of parent (root: `T(root) = (0,0,0)`)
- `R(θ(e))` = rotation matrix from `rotation_rule`
- `Δ(e)` = `(dx, dy, dz)` from `M_BOM_Line` (parent-relative offset)

**Critical property:** No accumulation. Each `T(e)` recomputed from parent, not from previous sibling.

### Stage R: Routing (Generative MEP → Expanded Placement)

```
R: (T_ARC, Λ_MEP, J) → T_MEP
```

For elements with no source IFC (RouteWalker output):

```
T_MEP = PatternMatch(Λ_MEP, Anchors(Ω_FIXTURE, Ω_METER), J)
```

Where:
- `PatternMatch` applies mined topology patterns (e.g., SP_TERMINAL_01)
- `Anchors` extracts connection points from fixture and meter OrderLines
- `Λ_MEP` includes gradient rules: `dz/dx ≥ 0.025` for SP

### Stage V: Validation (Compliance Check)

```
V: T → (PASS, BLOCK, WAIVE)ᵏ
```

For each rule `λ ∈ Λ` with jurisdiction `J`:

```
V_λ(T(e)) = 
  PASS   if constraint_λ(T(e)) ≥ threshold_λ
  BLOCK  if constraint_λ(T(e)) < threshold_λ AND NOT waived
  WAIVE  if user override attached
```

Where `constraint_λ` is one of:
- `MIN_DIMENSION(e) = min(width, depth, height)`
- `MAX_SPACING(e₁, e₂) = distance(T(e₁), T(e₂))`
- `MIN_GRADIENT(e) = dz / dx` (for SP pipes)
- `CLEARANCE(e₁, e₂) = min_distance(AABB(e₁), AABB(e₂))`

### Stage W: Write (Persist to output.db)

```
W: T → output.db
```

Writes the compiled geometry with element positions, product references, and validation results.
