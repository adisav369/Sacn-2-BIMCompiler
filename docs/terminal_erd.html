ROUTE as BOM Tree — Segments with M_AttributeSetInstance

A ROUTE is a BOM tree, not a flat list. Each segment has its own M_AttributeSetInstance (varying pipe length). Fittings are fixed-geometry BIM_Component. Branches are sub-BOMs. Val_Rule (ad_fp_coverage) constrains spacing, sizing, and routing method.

FP_MAIN_GF_01 (BOM, bom_category=FP) ├─ SEGMENT_01 M_Product: PIPE_CW_50MM │ └─ M_AttributeSetInstance: {length_mm: 3200} ← BIM_Pipe, IsInstance=1 ├─ FITTING_01 M_Product: ELBOW_90_50MM │ (no instance — BIM_Component, fixed geometry) ├─ SEGMENT_02 M_Product: PIPE_CW_50MM │ └─ M_AttributeSetInstance: {length_mm: 4800} ├─ TEE_01 M_Product: TEE_50x25MM │ └─ BRANCH_RUN_01 (sub-BOM!) │ ├─ SEGMENT_B1 PIPE_CW_25MM {length_mm: 1200} │ ├─ SPRINKLER_01 SPRINKLER_UPRIGHT_K80 (BIM_Component) │ ├─ SEGMENT_B2 PIPE_CW_25MM {length_mm: 4600} │ └─ SPRINKLER_02 SPRINKLER_UPRIGHT_K80 └─ SEGMENT_03 M_Product: PIPE_CW_50MM └─ M_AttributeSetInstance: {length_mm: 2100}
