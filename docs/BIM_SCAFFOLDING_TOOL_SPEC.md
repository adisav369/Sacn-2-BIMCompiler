# BIM Compiler — Addon Scaffolding Tool Specification

**Project:** BIM Intent Compiler
**Date:** 2026-02-02
**Status:** Design (Build after features stabilize)

---

## Purpose

A command-line tool that generates all required files when adding a new space type to the BIM Compiler vocabulary. Ensures completeness across all layers and enforces contracts.

---

## Why Build This

| Without Scaffolding | With Scaffolding |
|---------------------|------------------|
| Remember which files to edit | Generated for you |
| Copy patterns from similar types | Template with all fields |
| Forget witness claims | Stub generated |
| Inconsistent structure | Identical every time |
| Manual tracking | Validator enforces |

---

## When to Build

**After features stabilize.** Current feature roadmap:
- Phase 51: Two-way structural grid
- Phase 52: Stair placement
- Phase 53: Multi-storey patterns
- Phase 54: Vertical MEP risers
- **Phase 55: Scaffolding tool** ← Build here

Building scaffolding before features stabilize means constant updates to templates.

## Usage

### Basic Command

```bash
addon-scaffold PRAYER_HALL --category HABITABLE
```

### With Options

```bash
addon-scaffold PRAYER_HALL \
  --category HABITABLE \
  --structural \
  --wet-room=false \
  --output addons/religious/
```

### Generated Output

```
Generated:
  addons/religious/prayer_hall.addon.yaml    ← Master template
  config/spacetypes.yaml                      ← Entry appended
  src/.../witness/PrayerHallClaims.java      ← Stub methods

  2. Run: addon-validate addons/religious/prayer_hall.addon.yaml
  3. Run: addon-integrate addons/religious/prayer_hall.addon.yaml
```
