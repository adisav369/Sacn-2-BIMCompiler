SECTION 6: KNOWN GAPS AND OPEN ITEMS
────────────────────────────────────────────────────────────────────────────────

GAP-T-01  COURTYARD and LINEAR strategies not implemented
          ad_typology_template CHECK allows these grid_strategy values but
          TopologyBatchProcess.STRATEGIES map only has "STRIP_ZONES".
          Severity: LOW (no data rows use them yet)

GAP-T-02  DINING_PREFAB_MY missing
          ad_room_slot maps DINING→LIVING_PREFAB_MY as fallback.
          Comment in migration notes "add DINING_PREFAB_MY later".
          Severity: LOW (workaround acceptable for TERRACE_MY_1S)

GAP-T-03  Phase 4b gap: TopologyMaker does not create c_orderline rows
          TopologyWriter.registerBuilding() creates an c_order entry
          (doc_status=CO, provenance=GENERATIVE) but NO c_orderline BOM Drop rows.
          Without these, DAGCompiler cannot compile the generative building.
          Severity: HIGH — BomTierResolver (Phase 4b) required to close this.

GAP-T-04  ad_room_slot.min_area unit mismatch with ad_ubbl_rule.min_value_mm
          min_area is in m² (e.g., 9.29, 2.50, 1.50).
          ad_ubbl_rule.min_value_mm for AREA is in mm² (e.g., 9,290,000).
          Mixed units on the same concept — risk of comparison error if compared directly.
          Severity: MEDIUM — recommend rename to min_area_m2 or convert to mm².

GAP-T-05  Migration bootstrap UBBL values are wrong until ubbl_slots is applied
          migration_topology_maker_bootstrap.sql Part 3 seeds UBBL_BED_AREA=9290
          (should be 9,290,000 mm²). This is corrected by migration_topology_ubbl_slots.sql.
          If bootstrap is applied alone (fresh DB, no canonical DB copy), validator
          would use incorrect thresholds. Test setup copies canonical DB so this is
          masked. A future clean-from-scratch scenario would fail.
          Severity: MEDIUM — idempotent on canonical DB; risky on fresh DB

GAP-T-06  TopologyBatchProcess Javadoc step 4 references ad_spatial_rule (wrong)
          Actual table is ad_ubbl_rule. ad_spatial_rule is an AD Events table.
          Severity: LOW (documentation only)

GAP-T-07  TopologyWriter.writeBom() uses raw JDBC — not PO-wrapped
          Noted as low-priority; ad_bom/ad_bom_child outside current PO scope.
          Severity: LOW

GAP-T-08  UBBL constraints CEILING_MM and NOT_ADJACENT not validated at runtime
          UbblValidator explicitly skips these. 16 UBBL rules loaded but only
          AREA and MIN_DIM are checked.
          Severity: MEDIUM — ceiling height compliance not enforced generatively

GAP-T-09  BEDROOM_PREFAB_MY_3100 light offset hardcoded for 3.1m room
          LIGHT placed at dx=1.55, dy=1.55 (centred in 3.1×3.1m room).
          If room is larger, light is off-centre. The offset should be derived
          from room centroid, not a fixed absolute offset in the BOM child.
          Severity: LOW (cosmetic; lighting position not structurally critical)

GAP-T-10  Only one typology seeded (TERRACE_MY_1S)
          TB-LKTN grid documented but not formalised as an ad_typology_template row.
          Multi-storey typologies not represented.
          Severity: MEDIUM — blocks TB-LKTN generative path

GAP-T-11  bom_category Java dispatch not implemented
          bom_category column live on ad_bom and ad_building.
          BOMAssemblerAD.lookupSlots() does not yet filter by bom_category.
          WatchDog §1.15: "Java dispatch pending".
          Severity: MEDIUM (data ready; Java wire needed)
