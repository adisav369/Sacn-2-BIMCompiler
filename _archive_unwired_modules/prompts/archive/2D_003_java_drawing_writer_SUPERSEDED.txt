
`writeFloorPlan`:

- Render: heavy lines for CUT (0.5mm exterior, 0.35mm interior), light for BELOW (0.15mm)
- Apply line weights from 2D_ARCHITECTURAL_LAYOUT.md §7

`writeElevation`:
- Load mesh vertices from base_geometries
- Project onto XZ (N/S face) or YZ (E/W face)
- Convex hull for roof elements (port _convex_hull_2d from Python)
- Render with level markers at FFL/CLG/RIDGE
