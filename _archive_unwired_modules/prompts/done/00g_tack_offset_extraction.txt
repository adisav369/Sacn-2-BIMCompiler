### The spec maths (§7)

```
child_pos − parent_pos = dx/dy/dz
```

Same subtraction as ARC walls and slabs. Tack point = pipe-end face centre
(not LBD corner). For a pipe aligned along X: inlet face centre = (minX, cy, cz),
outlet face centre = (maxX, cy, cz). For consecutive touching pieces: the
dx on the next M_BOM_Line ≈ (next_piece_cx − this_piece_cx).

IFCtoERP writes to ERP.db only (read-only access to *_extracted.db — never modify).

## Task

### Algorithm: spatial proximity chain detection

No connectivity graph is available in *_extracted.db (mep_systems/system_nodes/
system_edges tables exist in HospitalAuckland_extracted.db but are empty). Use AABB
spatial adjacency:

1. **Group** MEP elements by (storey, discipline, dominant_axis). Discipline is
   `elements_meta.discipline` — for RM all MEP is `"MEP"`, use ifc_class to
   classify further (IfcPipeSegment/Fitting = CW or SP, IfcDuctSegment/Fitting
   = ACMV, IfcFireSuppressionTerminal = FP, IfcFlowTerminal = SP/CW).

2. **Dominant axis**: for each group, determine which axis (X, Y, Z) has the
   most variance in element centroids. This is the run direction.

3. **Sort** elements along the dominant axis (by centroid).

4. **Chain**: consecutive elements whose AABB faces nearly touch (gap < 50mm)
   are connected. Start a new run when gap exceeds 50mm.

5. **Offset**: for each connected pair (parent P, child C):
   - dx = C_cx − P_cx  (centroid X difference, metres)
   - dy = C_cy − P_cy
   - dz = C_cz − P_cz

6. **Shim as first line**: each recipe starts with the discipline-appropriate
   shim at dx=0, dy=0, dz=0. Shim product_id lookup: use existing
   `_shim_attributes` table in ERP.db (e.g. FP → FP_CEILING_SHIM).

7. **Product ID** for each piece: resolve from `_import_joint_piece_types`
   via (piece_type, rounded_diameter_mm, material). Same key as J1 used.
