## Concept

COMPLETE(ifc_class, storey, product_id) places walls along the four faces of each IfcSpace
that has a deficit. Uses:
- `T(p(space))` = IfcSpace centroid from element_transforms
- AABB from elements_rtree → face positions (N/S/E/W)
- Product dimensions from component_library.db M_Product (length, thickness, height)
- Output: new element rows in output.db + W_BOM_Variance record

### Task 2 — Placement algorithm

For each IfcSpace with deficit at the target storey:

1. Load AABB from `ifc_spaces` table (NOT elements_rtree — see Edit_003):
   SELECT min_x, max_x, min_y, max_y, min_z, max_z, center_x, center_y, center_z
   FROM ifc_spaces WHERE guid=space_guid
2. Load product dims from component_library.db: (thickness_mm, height_mm)
3. For each face (N/S/E/W) where no IfcWall exists within snap_tolerance=50mm:
   - N face: centre = (midX, maxY, midZ), length = maxX-minX, θ=0°
   - S face: centre = (midX, minY, midZ), length = maxX-minX, θ=180°
   - E face: centre = (maxX, midY, midZ), length = maxY-minY, θ=90°
   - W face: centre = (minX, midY, midZ), length = maxY-minY, θ=270°
4. Insert element_instances (guid=UUID, ifc_class=ifcClass)
5. Insert element_transforms (center_x/y/z from step 3)
6. Insert elements_rtree (AABB from centre + product dims)
7. Insert W_BOM_Variance (gesture_type=PANEL or ADD, resolved_type=LINE_ADD,
   resolution_level=2, verb_sequence="COMPLETE IfcWall <storey> FACE <face> PRODUCT <pid>")

### Task 3 — Existing wall check

Before placing a wall on a face, check if one already exists within snap_tolerance:
```
existing = COUNT(*) FROM element_transforms et
           JOIN elements_meta em ON em.guid=et.guid
           WHERE em.ifc_class='IfcWall'
           AND ABS(et.center_x - face_cx) < snap_tolerance
           AND ABS(et.center_y - face_cy) < snap_tolerance
```
If existing > 0: skip that face (wall already there).
