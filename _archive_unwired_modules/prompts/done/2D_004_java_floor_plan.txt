## PROFESSIONAL READABILITY STANDARDS (added 2026-04-06, ref §14.7)

All SVG output must meet ISO 128 / TB-LKTN pen scale before marking DONE.
Read `2D_ARCHITECTURAL_LAYOUT.md §14.7` for the full table. Summary:

**Line weights (SVG stroke-width in mm):**
- LW_GROUND = 0.70   — ground line only (boldest — visual base)
- LW_WALL_EXT = 0.50 — section-cut exterior walls, roof outline
- LW_WALL_INT = 0.35 — partitions, doors, apron step
- LW_OPENING  = 0.35 — window/door outlines
- LW_WALL_GLASS = 0.25 — glazing / curtain wall
- LW_DIMENSION = 0.18 — dims, extension lines, hatching, grid (ISO hairline)
- **0.15 mm is BANNED** — prints as 1px, invisible on A3; use 0.18 minimum

**Text heights (mm on paper at 1:100):**
- Drawing title: 5.0, Room label: 3.5, Grid bubble: 3.0, Dims/levels: 2.5

**Label spacing:**
- Minimum gap between adjacent level markers: 3 × TXT_DIM (= 7.5mm)
- When markers are closer, use leader line offset — marker triangle at true level,
  text box shifted with a thin (0.18) vertical leader

**Grid bubbles:**
- Radius = 4.0mm (8mm diameter) — do not reduce

**Dash patterns (scale-aware — currently hardcoded, must fix in Java):**
- CENTER (grid): `(4s, 1s, 1s, 1s)` where s = SCALE/100
- HIDDEN: `(4s, 2s)` — at 1:100 s=1.0, at 1:50 s=0.5

**Mirror rule for rear/right elevations:**
- 'rear': h = -x (viewer sees X reversed — west on right, east on left)
- 'right': h = -y (viewer sees Y reversed)
- Grid positions: multiply by h_sign before mapping to paper
- Roof hull: negate h_vals for mirrored faces
- Without this, front/rear elevations show identical roof tilt (wrong)
