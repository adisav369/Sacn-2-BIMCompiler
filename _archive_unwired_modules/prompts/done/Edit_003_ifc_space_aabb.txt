## Concept

The placement formula `T(wall) = T(p(space)) + R(θ) · Δ(face)` requires IfcSpace centroid
and AABB. Currently `placement_extractor.py` skips IfcSpace geometry — only structural/MEP
elements get AABB. This task extends extraction to include IfcSpaces.

IfcSpace geometry is available from the IFC file as `IfcRelSpaceBoundary` or directly from
the IfcSpace's geometry representation. IfcOpenShell can extract it.

**CRITICAL:** Do NOT write IfcSpace rows to `elements_meta` or `elements_rtree`.
G1-COUNT gates count those tables. Instead, create a dedicated `ifc_spaces` table.

First, add the table if it doesn't exist (idempotent — safe to run on existing DBs):

```sql
CREATE TABLE IF NOT EXISTS ifc_spaces (
    guid      TEXT PRIMARY KEY,
    name      TEXT,
    storey    TEXT,
    min_x     REAL, max_x REAL,
    min_y     REAL, max_y REAL,
    min_z     REAL, max_z REAL,

```

For each IfcSpace in the IFC file:
1. Get geometry via IfcOpenShell (`space.Representation` → vertices)
2. Compute AABB and centroid from vertices
3. INSERT into `ifc_spaces` (not elements_meta, not elements_rtree)
4. Get storey from `spatial_structure` WHERE guid=space.GlobalId → parent

If IfcSpace has no geometry: use AABB of all elements in `rel_contained_in_space`
where space_guid = this space. Log: `[SPACE_APPROX] Space X: using contained envelope`.
