## Concept

The section cut slices triangle meshes at a given Z height, producing 2D line segments.
These are chained into closed contours (wall outlines with window/door gaps).

The algorithm (from Python reference):
```
For each triangle (v0, v1, v2):
  For each edge straddling cut_z:
    t = (cut_z - va.z) / (vb.z - va.z)
    px = va.x + t*(vb.x-va.x)
    py = va.y + t*(vb.y-va.y)
  Two intersection points → one LineSegment2D
Chain segments by endpoint proximity (tolerance=0.5mm) → List<Contour>
```
