## Concept

The Synthetic Rosetta Stone test (SPATIAL_VARIANCE_SRS.md §12) needs to programmatically
measure element dimensions in the generated SVG — specifically wall lengths at section cut
height. Rather than parsing SVG XML, the simpler path is to add a `--measure` flag to
drawing_writer.py that prints element measurements to stdout as CSV.

The test (in 2D_001) calls drawing_writer.py with --measure and reads the CSV output.

## Task — Add --measure flag to drawing_writer.py

In `main()`, add argument: `parser.add_argument('--measure', action='store_true')`

In `draw_floor_plan()` (or a wrapper), after computing CUT element contours:
- For each CUT element: compute the length of the longest contour segment
  (approximation of wall face length in plan)
- Print to stdout as CSV:
  ```
  guid,ifc_class,element_name,storey,contour_length_mm
  abc123,IfcWall,Ext_Wall_N,Ground Floor,4200.0
  ...
  ```
- Only print when `--measure` is passed. Normal SVG output unchanged.

Length calculation for a contour: max distance between any two consecutive points,
or sum of all segment lengths for open contours. Use the section_cut contour already
computed — do not re-cut.
