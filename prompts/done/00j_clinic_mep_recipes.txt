## Questions to answer

### Q1: Routing topology or coverage topology?

For each of CE, CH, CP: what % of MEP elements have null storey?
If >80% null → coverage topology triggered. Expected: all three are routing topology
(they have declared storeys in YAML and IFC).

### Q2: Chain geometry — do runs make sense?

For each building:
- How many MEP runs? How many lines?
- Largest run size? Any runs > 50 pieces?
- Any degenerate discards (total offset < 10mm)?
- Any collinearity discards (R² < 0.5)?
- How many non-zero rotation_rule values?

### Q3: Distribution — not bunched

Key check from user requirement: are elements spread across space or all in one spot?

```sql
SELECT disc, COUNT(*) runs,
  ROUND(MIN(ABS(dx)+ABS(dy)+ABS(dz)),3) min_offset,
  ROUND(MAX(ABS(dx)+ABS(dy)+ABS(dz)),3) max_offset,
  ROUND(AVG(ABS(dx)+ABS(dy)+ABS(dz)),3) avg_offset
FROM M_BOM_Line l JOIN M_BOM b ON l.M_BOM_ID=b.M_BOM_ID
WHERE b.source_building IN ('Clinic_Electrical','Clinic_HVAC','Clinic_Plumbing')
  AND l.sequence > 20
GROUP BY disc, b.source_building
```

Offset range should span 0.1–20m. If all offsets are near-zero → degenerate data slipped through.
If max = min → all elements at same position → spatial defect in source IFC.

### Q4: DISC qty alignment

Check whether the recipe run count aligns with element count from extraction:
```
CE: 2081 MEP elements → expect ~100-500 runs (2-20 pieces/run typical)
CH:  555 MEP elements → expect ~30-100 runs
CP: 6584 MEP elements → expect ~300-1000 runs
```
Gross mismatch (e.g., 1 run for 6584 elements) = topology defect.

### Q5: Penetration gaps

Any cross-floor gaps (50-600mm) merged via structural AABB?
These are multi-floor clinic buildings — pipe risers through slabs are expected.
Report: how many structural AABBs loaded per building? Any penetration merges?

### Q6: IFC storey naming mismatch

CE uses "Level 1/2", CH uses "First Floor/Second Floor", CP uses "Level 1/2".
All are part of the same physical building but in separate IFC files.
`toStoreyCode()` maps:
- "Level 1" → "L1"
- "First Floor" → "FF" (uppercase initial letters)

If CH produces storey codes "FF/FS/FDN" vs CE/CP "L1/L2/FDN" — different codes for the
same physical floor. This is a finding to report, not a blocker.
