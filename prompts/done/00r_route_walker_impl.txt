### A1. Pattern selection

```sql
-- Select patterns for CW and SP. Match building_type exactly; fall back to any if no match.
SELECT pattern_id, discipline, building_type, sequence, from_node_type, to_node_type,
       direction_axis, piece_type, offset_rule, gradient
FROM ad_mep_pattern
WHERE discipline IN ('CW','SP')
ORDER BY discipline, sequence
```

No exact RESIDENTIAL match exists yet — the fallback selects TERMINAL patterns. Log which
pattern_id was selected per discipline.

### A2. Anchor loading

```sql
SELECT anchor_id, anchor_type, x_m, y_m, z_m, storey
FROM ad_mep_anchor
WHERE source_building = ?
```

Map anchor_type → node_type for pattern matching:
- `METER`   → node_type `METER` (CW) or `STACK` (SP — boundary element = stack point)
- `FIXTURE` → node_type `FIXTURE`
- `VALVE`   → node_type `VALVE`
- `GENERIC` → node_type `JUNCTION`

### A3. Pattern application (per discipline, per storey)

For each discipline (CW, SP):
  For each storey (group anchors by storey):
    Walk pattern steps in `sequence` order:
    1. Collect from_anchors = anchors WHERE node_type == step.from_node_type
    2. Collect to_anchors   = anchors WHERE node_type == step.to_node_type AND not yet used
    3. Pair each from_anchor with its nearest unmatched to_anchor (Euclidean distance XY only)
    4. Skip pairs where distance = 0 or > 50m (sanity guard — no cross-building links)
    5. For GRADIENT steps: dz = gradient × horizontal_distance (MS 1228 §5.3 min 0.025)
    6. Clash check: pipe AABB vs ARC envelope (§A4)
    7. If no clash: emit c_orderline row (§A5); mark to_anchor as used

### A4. ARC envelope clash check

```sql
-- ARC envelope: walls, slabs, ceilings from compile DB
SELECT dx, dy, dz, aabb_width_mm, aabb_depth_mm, aabb_height_mm
FROM c_orderline WHERE Discipline = 'ARC' AND IsActive = 1
```

Generated pipe AABB: centre = midpoint of anchor pair, dims = (pipe_diameter_mm × 1.5) in
cross-section, length in dominant axis direction. Use nominal diameter 50mm (default) until
piece_type lookup is implemented.

Clash: pipe AABB intersects ARC AABB → skip this pair, log WARNING with anchor IDs. Do NOT
throw — some penetrations may be legitimate. Count skipped pairs.

### A5. Emit c_orderline row

```sql
INSERT INTO c_orderline
(C_Order_ID, Parent_OrderLine_ID, Line, family_ref, host_type,
 M_Product_ID, Discipline, AD_Org_ID, Qty, dx, dy, dz,
 aabb_width_mm, aabb_depth_mm, aabb_height_mm, IsActive)
VALUES (?, NULL, ?, 'MEP_ROUTE', 'GENERATED',
        ?, ?, ?, 1, ?, ?, ?,
        50.0, 50.0, ?, 1)
```

- `C_Order_ID`: same as orderId parameter
- `Line`: sequential (max existing Line + 10 per discipline block)
- `M_Product_ID`: resolve from `_import_joint_piece_types` WHERE piece_type = step.piece_type
  AND source_building matches; if not found use piece_type string directly (placeholder)
- `Discipline`: step.discipline ('CW' or 'SP')
- `AD_Org_ID`: 6 for CW, 7 for SP (from Discipline enum)
- `dx,dy,dz`: anchor_end.x - anchor_start.x, etc. (metres)
- `aabb_height_mm` (length): Euclidean distance × 1000
