## Background

The G3 bug has two manifestations:

**Bug A (line 799) — routing topology branch ignores elements_meta.discipline:**
```java

```
The COVERAGE TOPOLOGY branch at line 759 already does it correctly:
```java

```
Effect on TE: all IfcPipeSegment (CW=619, SP=455, FP=2672, LPG=75) are collapsed to CW
because the keyword heuristic defaults everything without "soil/drain" to CW.

**Bug B (2-arg discFromClass, line 994–997) — IfcFlowTerminal light fixtures → CW:**
```java
case "IfcFlowTerminal" -> {
    String et = elementType != null ? elementType.toLowerCase() : "";
    yield (et.contains("drain") || ... ) ? "SP" : "CW";   // BUG: no ELEC path
}
```
Effect on CE/CH/CP: RM light fixtures (IfcFlowTerminal, no drain keyword) → CW.
Generates hundreds of spurious CW MEP_RECIPE BOMs for lighting elements.
Note: the anchor code (extractAnchors()) already skips light fixtures correctly —
this fix only affects discFromClass used in recipe building and routing.
