## Concept

Many discipline-only IFC files have zero IfcWall elements. The compiler currently compiles
what exists silently. This task adds detection: a service that queries element counts against
expected minimums and emits COMPLETION_OPPORTUNITY records.

This is purely read-only. No BOM changes. No geometry. No variance. Just detection.

### Task 3 — CompletionAuditService.java

```java
/**
 * Detects missing element types per storey.
 * Implementing FINISH_WALLS_SRS.md §3, BIM_Designer_SRS.md §28.17.1
 * Witness: W-FW-DETECT
 */
public class CompletionAuditService {
    public List<CompletionOpportunity> audit(String buildingId, String ifcClass);
}
```

Algorithm:
1. Query `spatial_structure` for all storeys of this building
   (type='IfcBuildingStorey', parent chain from building_id)
2. For each storey: COUNT elements_meta WHERE storey=S AND ifc_class=ifcClass
3. Query `ad_completion_rule` WHERE ifc_class=ifcClass AND product_category=B.product_category
4. If actual < min_count: emit CompletionOpportunity
5. Log: `[COMPLETION] Building X, Storey Y: actual/expected IfcWall (deficit=N)`

Note: product_category lookup requires joining to erp.db (M_Product for this building's
root BOM). If unavailable, use 'RESIDENTIAL' as default. Check PROGRESS.md for current
join path.
