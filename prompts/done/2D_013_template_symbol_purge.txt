# 2D_013 — Template Symbol Purge + MEP Template + Log Proof

## Mission
Eliminate all hardcoded symbol geometry from `drawing_writer_dxf.py`.
Every visual element must read from `drawing_template.json` or `2D.db`.
Every parameter read must emit `§VALUE` so the coder knows from logs
what was drawn without opening the file. Addresses I-12, I-13, I-14.

1. `2D_Layout/docs/2D_ARCHITECTURAL_LAYOUT.md` §1 R5 (no hardcoded symbols)

5. Run baseline: `python3 drawing_writer_dxf.py ../input/DX_extracted.db --all`
   Confirm 6/6 PASS, read summary + "CHECK PROBLEMS" line.

## Approach
One symbol at a time. For each: add template key → read in code → emit
`§VALUE` log → remove hardcoded value → run → verify from log output.
Do NOT batch. Prove each from the log before moving to the next.

## Step 3 — Refactor MEP code to read template

In `_classify_mep()`: read keywords from `tpl['mep']['electrical_keywords']`
and `tpl['mep']['plumbing_keywords']` instead of module constants.

In `_draw_mep_symbol()`: read shape, layer, radius from
`tpl['mep']['symbols'][discipline]` and `tpl['mep']['terminal_symbol_radius_mm']`.

In `write_mep_plan_dxf()`: read line weights from template.

Each read → `§VALUE` log line.

## Step 6 — Add §RENDER log for every symbol

Every symbol drawn must log what it is and where the definition came from:
```
§RENDER BUBBLE layer=A-GRID r=4.0mm at (x,y) src=template.grid.bubble_radius_mm
§RENDER NORTH_ARROW shape=triangle size=8.0mm at (x,y) src=template.north_arrow
§RENDER MEP_SYMBOL shape=circle_cross r=2.5mm at (x,y) src=template.mep.symbols.ELECTRICAL
§RENDER SLOPE_ARROW head=1.5mm at (x,y) src=template.roof_plan.slope_arrow_head_mm
§RENDER DIM_TICK angle=45° len=1.5mm src=template.dimensions.tick_angle_deg
```

Witness: grep log for `§RENDER.*src=template` — every symbol has a template source.

## Lessons for coder
- You cannot see the drawing. The log is your only evidence.
- If a symbol has no `§VALUE` log, you have no proof it was drawn correctly.
- Hardcoded geometry is invisible to tests — template keys make it testable.
- Fix one symbol at a time. Run after each. Read the log diff.
- "CHECK PROBLEMS" at end of every log — read §18.1 even when all tests pass.
