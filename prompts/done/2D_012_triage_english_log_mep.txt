### P0a — Hatch patterns (section cut material fills)

Source: `bim/data/assets/patterns.svg` — 30+ SVG pattern definitions.
Extract 5 key patterns into ezdxf HATCH pattern defs in `_new_doc()`:

| Pattern | SVG id | Use case |
|---------|--------|----------|
| Concrete | `concrete` | Wall/slab section cuts |
| Brick | `brick` | Brick wall sections |
| Insulation | `insulation` | Cavity wall fill |
| Wood | `wood` | Timber sections |
| Earth | `earth` | Site/foundation sections |

Steps:
1. Read `patterns.svg`, extract line geometry for each pattern
   (SVG `<line>` or `<path>` within `<pattern>` elements)
2. Convert SVG coordinates to ezdxf hatch pattern format:
   `[angle, base_point, offset, dash_length_items]`
3. Register patterns in `_new_doc()` via `doc.pattern.add(name, lines)`
4. In wall rendering loop, select pattern by material:
   `material_name` from `ElementSection` → pattern lookup
5. Replace `_add_wall_hatch(msp, pts)` solid fill with material pattern
   (keep solid black as fallback when material unknown)

Witness: `§HATCH concrete: 8 walls, brick: 3 walls` in diagnostic log.
