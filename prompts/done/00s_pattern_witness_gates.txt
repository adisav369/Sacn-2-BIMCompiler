### A2. W-PATTERN-CW: all FIXTURE anchors served

```java
@Test void w_pattern_cw_fixture_coverage()
```

From `library/ERP.db`: count of FIXTURE anchors for source_building='HospitalAuckland' = F.
From `hospitalauckland.db` c_orderline WHERE Discipline='CW' AND family_ref='MEP_ROUTE': count = N.
Assert: N ≥ F (at least one CW line per fixture anchor — each fixture has a supply pipe)

Note: F=11 from 00q. If RouteWalker paired each FIXTURE with a METER step, N ≥ 11.

### A3. W-PATTERN-CW: no diagonal segments

```java
@Test void w_pattern_cw_no_diagonal()
```

For each CW MEP_ROUTE c_orderline row, read dx, dy, dz.
A segment is axis-aligned if at most one of |dx|, |dy|, |dz| is non-zero
(tolerance: ≤ 0.001m in the two non-dominant axes — floating point).
Assert: ALL CW MEP_ROUTE rows are axis-aligned. Count violations; fail with count if > 0.

### A4. W-PATTERN-CW: clash = 0

```java
@Test void w_pattern_cw_no_arc_clash()
```

For each CW MEP_ROUTE row, construct pipe AABB (centre from dx/dy/dz accumulation from
parent, width/depth from aabb_width_mm/aabb_depth_mm, height from aabb_height_mm).
For each ARC c_orderline row, construct ARC AABB similarly.
Assert: zero AABB intersections (use a tolerance of -10mm — pipes may touch walls but
not penetrate). Log any clashes found before failing.

### A5. W-PATTERN-SP: SP network exists with gradient

```java
@Test void w_pattern_sp_gradient_compliant()
```

For each SP MEP_ROUTE c_orderline row WHERE offset_rule includes 'GRADIENT' context
(or: WHERE dz != 0 and the horizontal extent > 0):
  Compute slope = |dz| / sqrt(dx² + dy²)
  Assert: slope ≥ 0.024 (allow 4% below 0.025 for floating-point — MS 1228 §5.3)
Log any segments with slope < 0.025. Fail if any gradient segment has slope < 0.024.

Note: DIRECT segments (Z-axis drops for stacks) are excluded — only GRADIENT steps checked.

### A6. W-PATTERN-SP: STACK anchor coverage per storey

```java
@Test void w_pattern_sp_stack_per_storey()
```

From `library/ERP.db`: SELECT DISTINCT storey FROM ad_mep_anchor

Assert: at least 1 METER/STACK anchor exists per storey (minimum 1 drainage stack per floor).
This is a data assertion (00q extracted 154 METER anchors) — if 0 per storey, flag WARNING not FAIL.

### A7. W-PATTERN-SP: FIXTURE anchors drain to STACK

with no stack in immediate storey, deferred to 00t).
