as walls show thickness in the floor plan — two concentric outlines
(outer eave boundary + inner soffit boundary), not a single line.

## Data source — no invention permitted

The vertex blob is in `base_geometries`:

```sql
SELECT bg.vertices, bg.vertex_count
FROM elements_meta m
JOIN element_instances ei ON m.guid = ei.guid
JOIN base_geometries bg   ON ei.geometry_hash = bg.geometry_hash
WHERE m.ifc_class = 'IfcRoof'
```

`parse_vertices_blob(blob, vertex_count)` → numpy array shape (N, 3).
Columns: [X, Y, Z] in world metres.

**Do not query this at test time — query it at draw time in
`write_roof_plan_dxf`. The function already has `db_path`.**

## Step 1 — Extract roof mesh vertices at draw time

In `write_roof_plan_dxf`, before the `# ── Roof outline ──` block,
add a helper that loads the actual XY projection:

```python
def _roof_mesh_hulls(db_path):
    """Return (outer_hull, inner_hull) for IfcRoof elements.
    outer_hull: XY convex hull of ALL mesh vertices (top-down eave boundary).
    inner_hull: XY convex hull of BOTTOM-FACE vertices (soffit boundary).
    Both are lists of (x_m, y_m) in world metres.
    Returns ([], []) if no mesh data.
    """
```

Implementation rules (no invention):
- Load vertices via `parse_vertices_blob` — same function as `roof_silhouette`
- Project to XY: `xy_all = verts[:, :2]`  (columns 0 and 1)
- `outer_hull = _convex_hull_2d([(x, y) for x, y in xy_all])`
- For inner hull: filter vertices where Z ≤ `z_mean - z_span * 0.2`
  (bottom fifth of the Z range) → `xy_inner` → `_convex_hull_2d(xy_inner)`
- If `len(outer_hull) < 3` → return `([], [])`
- Log vertex counts: `§DATA roof mesh: N_all vertices, N_inner bottom vertices`
- Log hull sizes: `§DATA outer hull: K points, inner hull: J points`

Witness: `§DATA` lines appear in log for SH run.

## Step 2 — Replace the bbox rectangle with the mesh hull

Find and remove:

```python
# ── Roof outline (bold) ──
ro_pts = [(_mh(roof_min_x), _mh(roof_min_y)), (_mh(roof_max_x), _mh(roof_min_y)),
          (_mh(roof_max_x), _mh(roof_max_y)), (_mh(roof_min_x), _mh(roof_max_y))]
msp.add_lwpolyline(ro_pts, close=True,
                   dxfattribs={'layer': 'A-ROOF', 'lineweight': lw_wall})
```

Replace with:

```python
# ── Roof outline: mesh hull (§1 R1 — no bbox invention) ──
outer_hull, inner_hull = _roof_mesh_hulls(db_path)
if len(outer_hull) >= 3:
    outer_pts = [(_mh(x), _mh(y)) for x, y in outer_hull]
    msp.add_lwpolyline(outer_pts, close=True,
                       dxfattribs={'layer': 'A-ROOF', 'lineweight': lw_wall})
    _log(f"§RENDER ROOF_OUTER hull={len(outer_pts)} pts src=base_geometries.vertices")
else:
    # Fallback: only if no mesh data at all (not an excuse to invent)
    _log("§WARN ROOF_OUTER no mesh data — skipping outline (R1: no invention)")

if len(inner_hull) >= 3:
    inner_pts = [(_mh(x), _mh(y)) for x, y in inner_hull]
    msp.add_lwpolyline(inner_pts, close=True,
                       dxfattribs={'layer': 'A-ROOF', 'lineweight': lw_part})
    _log(f"§RENDER ROOF_INNER hull={len(inner_pts)} pts src=base_geometries.vertices")
```

Line weights from template:
- Outer hull → `lw_wall` (wall_exterior_cut, already read)
- Inner hull → `lw_part` (wall_partition_cut, already read)
- No new line weight literals

Witness: log shows `§RENDER ROOF_OUTER hull=K pts src=base_geometries.vertices`.
