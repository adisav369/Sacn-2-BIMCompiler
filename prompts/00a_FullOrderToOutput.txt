## Concept

Compilation reads `*_BOM.db` (produced by 00_FullIFCtoBOM). The YAML's only role
at compile time is to name the **rootBOM** (`building_bom_id`). That rootBOM becomes
`C_OrderLine.M_Product_ID`. The Product Callout then generates DISC OrderLines
automatically from the BOM's discipline metadata.

Pipeline: `rootBOM → C_OrderLine → Product.Callout → DISC OrderLines → BOM explosion → elements → output.db`

No YAML fields are parsed during compilation except:
- `building_bom_id` — the root BOM to compile
- `prefix` — output file naming
- `product_category` — passed as `-Dproduct.category` to Java

Everything else (storeys, rooms, disciplines, MEP routing) comes from the BOM
and ERP.db, not from YAML.
