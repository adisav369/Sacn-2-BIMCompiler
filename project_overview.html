What this is: An open-source compiler that reads IFC building models and produces verified Bills of Materials in ERP format. No geometry invention — 100% extraction with SHA256 proof. Construction treated as manufacturing: intent in, material orders out.

Buildings by Element Count

Architecture

4 Databases

component_library.db → LOD catalog (2,459 products, 44K geometries)
*_BOM.db → Per-building BOM dictionary
ERP.db → Discipline rules + 415 mined dimension rules
output.db → Compiled result (fresh each run)

Prime Rule

EXTRACT OR COMPILE ONLY. Query the database. Copy patterns you find. Compute positions via verbs. Never invent. Every element traces to a library source.

ERP Pattern

iDempiere-native tables: M_Product, M_BOM, M_BOM_Line, C_Order, C_OrderLine. Output is ready for procurement, scheduling, and costing — no translation layer needed.

Building Registry — 34 Onboarded Buildings

Each building is extracted from a real IFC file. No synthetic data. Same pipeline, same gates — only configuration changes. New IFCs are validated against 415 mined dimension rules from 20 buildings.
